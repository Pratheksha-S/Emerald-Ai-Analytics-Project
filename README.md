## About the Project

A smart, interactive Power BI dashboard built to turn Emerald Jewelry's raw sales data into actionable revenue decisions — paired with a conversational AI layer that lets anyone query the dashboard's insights in plain language.

- **235,000+** sales transactions analyzed
- **2013–2026** date range
- **4** branches, **6** product categories
- **7** dashboard modules covering trends, branch performance, pricing, and margins

## Key Insights

- **CBEXRD** branch contributes ~52% of total revenue — the single largest driver
- **Gold jewellery** makes up 86% of sales value, dominating the product mix
- Sales consistently peak in **November**, ahead of the wedding/festive season
- Gold jewellery margin holds at **81–82%**, the strongest-performing segment by profitability
